# Clinic Management System

## Project Description
This is a Clinic Management System database project developed using MySQL. The system manages patients, doctors, appointments, prescriptions, and billing records.

## Features
- Patient Management
- Doctor Management
- Appointment Scheduling
- Prescription Records
- Billing Management

## Database Tables
1. Patients
2. Doctors
3. Appointments
4. Prescriptions
5. Billing

## Technologies Used
- MySQL
- SQL

## How to Use
1. Create a MySQL database.
2. Run the provided SQL script.
3. The script will create all required tables.
4. Sample data is included for testing purposes.
